# Skills

Drop extra markdown files here. AnywhereBot loads every `*.md` except this README into its system prompt on startup.

A skill is just instructions: how to research, how to format notes, house style, a checklist. No code required.

- `example-research.md` — a starter research workflow that uses `web_fetch` and writes notes into `workspace/`.
- `free-models.md` — which free hosted / local models auto selects, and the ox-alpha / kimi-k3 paid warning.
- Add `skills/my-job.md` and restart the bot to teach it a new role.
